# Biblioteca de efeitos

Esta pasta contém 75 efeitos candidatos ativos. Cada pasta possui:

- `index.html` — demonstração contextual + área de código;
- `bloco-pronto.html` — bloco reutilizável;
- `bloco-pronto.txt` — espelho textual do bloco.

A lista ativa está em `../dados/efeitos.json`. Candidatos removidos da navegação estão registrados em `../dados/efeitos-arquivados.json`.
