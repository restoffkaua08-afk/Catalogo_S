# Padrão das demonstrações de efeitos

A demonstração deve usar o contexto real do efeito. Fundos ocupam uma seção inteira; vidro é aplicado à superfície de fundo de um painel; ícones são mostrados como ícones; sombras usam objetos neutros; elevação só acontece no hover.

A área externa das demonstrações usa preto. Uma superfície auxiliar pode ser usada apenas quando necessária para enxergar sombra ou relevo.

Famílias ativas: Fundos e telas, Ícones, Sombras e Elevação no hover.

Não adicionar efeitos apenas para aumentar a quantidade.
